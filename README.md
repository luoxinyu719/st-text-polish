## ✨ 功能特性

### 核心功能

| 功能 | 说明 |
|------|------|
| 🖋 **9 种润色风格** | 文学叙事、诗意朦胧、古典雅致、浪漫细腻、戏剧张力、极简冷峻、奇幻绮丽、暗黑哥特、完全自定义 |
| ⚡ **5 档润色强度** | 从「极轻微词句优化」到「完全重塑」，精确控制改动幅度 |
| 🏷 **快速预设标签** | 保留人称视角、增加感官细节、深化内心独白等 8 个常用选项，可多选叠加 |
| 📋 **一键导入** | 从 ST 当前输入框导入文字，或从最新 AI 消息导入 |
| 🔄 **流式输出** | AI 生成内容实时逐字显示，支持随时停止 |

### 对比与润色

| 功能 | 说明 |
|------|------|
| 🔀 **Diff 对比视图** | 润色前后差异高亮显示，红色为原文、绿色为新版 |
| 👆 **逐段选择** | 点击任意差异片段，自由选择保留原文还是新版 |
| 👁 **三种视图模式** | 全对比 / 只看原文 / 只看新版 / 最终预览 |
| 🔁 **重新生成** | 不满意当前 Diff？一键用相同意见重新生成 |
| ✏️ **修改意见** | 对润色结果输入具体要求，AI 针对性重写 |

### API 与配置

| 功能 | 说明 |

| 🤖 **自动拉取模型** | 连接后自动获取可用模型列表；中转 API 不支持时可手动填写 |

## 📦 安装方法

### 方法一：通过 SillyTavern 扩展管理器安装（推荐）

1. 打开 SillyTavern
2. 点击顶部**扩展图标**（🧩）
3. 点击「**安装扩展**」
4. 在输入框中粘贴以下地址：
   ```
   https://github.com/luoxinyu719/st-text-polish
   ```
5. 点击安装，等待完成提示
6. **刷新页面（F5）**

### 方法二：手动安装

1. 下载本仓库所有文件
2. 将文件夹放置到 SillyTavern 的以下目录：
   ```
   SillyTavern/public/scripts/extensions/third-party/st-text-polish/
   ```
3. 刷新 SillyTavern 页面

> **系统要求**：SillyTavern 1.10.0 及以上版本

## 📖 使用说明

安装完成后，在 SillyTavern 对话界面的**输入框上方**会出现：

```
✦ 文字润色
```

点击即可打开润色工坊弹窗。

---

### API 配置

首次使用需要配置 API，点击弹窗顶部的 **⚙ API** 标签页。

#### 第一步：选择 API 类型

| 类型 | 适用场景 |
|------|---------|
| **OpenAI 兼容** | 中转 API、第三方服务商、本地部署（推荐大多数用户选此项） |
| **Anthropic 原生** | 直连 Anthropic 官方 API（`api.anthropic.com`） |

#### 第二步：填写连接信息

- **API 地址**：填写服务商提供的地址，**无需加 `/v1` 后缀**
  - 例：`https://api.example.com`（中转）
  - 例：`https://api.anthropic.com`（官方）
- **API 密钥**：填写你的 Key（`sk-...`）

#### 第三步：连接并选择模型

点击「**连接并获取模型**」按钮：

- ✅ **成功**：自动拉取模型列表，从下拉框选择想用的模型
- ⚠️ **无法获取列表**（中转 API 常见）：在「当前模型」输入框**手动填写模型名称**，或点击下方的常用模型快速填入

> **中转 API 常见报错解决**：
> 如果报错 `No available channel for model XXX`，说明你的中转站套餐不包含该模型，换一个该服务商支持的模型即可。

#### 多档位管理

API 设置区顶部可管理多个配置档位：

- **新建**：点击 `+` 创建新档位（最多 5 个）
- **切换**：下拉框选择不同档位后立即生效
- **命名**：修改名称后点击 💾 保存
- **删除**：点击 🗑 删除当前档位（至少保留 1 个）

---

### 开始润色

1. 在「**待润色文本**」区域输入文字，或使用以下导入方式：
   - 「**导入输入框**」：抓取 ST 当前发送框里的文字
   - 「**导入消息**」：导入对话中最新的一条 AI 回复
2. 选择**风格**和**强度**
3. 按需选择**快速预设标签**（可多选）
4. 点击底部「**✦ 开始润色**」

生成完成后，结果会显示在下方，支持：
- **复制**：复制润色结果到剪贴板
- **发送**：将结果填入 ST 输入框
- **再次润色**：将结果放回输入框重新润色

---

### Diff 对比视图

对结果不满意时，在结果下方的输入框填写修改意见，点击 ✏️ 按钮，AI 会根据意见重写，并自动进入 **Diff 对比视图**。

```
红色删除线 = 原文内容
绿色高亮   = 新版内容
```

**操作方式：**
- 点击任意**红色片段** → 选择保留原文
- 点击任意**绿色片段** → 选择保留新版
- 顶部三个按钮可切换「原文 / 新版 / 最终预览」模式
- 点击「**应用**」确认修改，点击「**放弃**」取消
- 点击「**重新生成**」用相同意见再生成一次

---

### 润色历史

每次润色成功后，结果会自动保存到历史记录（最多保留 3 条）。

在「润色」Tab 底部点击「**润色历史**」展开折叠区域，可以：
- 查看历史记录的时间和输入预览
- 点击「**恢复**」将该条历史结果重新填入结果区
- 点击 ✕ 删除单条历史

---

### Prompt 编辑

点击 **📝 Prompt** 标签页，可以自定义发送给 AI 的 System Prompt。

> **提示**：System Prompt 告诉 AI「你是什么角色」，具体的风格、强度、预设要求由代码自动附加，无需手动写入。

- 修改后点击「**保存**」生效
- 点击「**恢复默认**」可重置为内置提示词

---

### 主题切换

点击 **🎨 主题** 标签页：

**内置主题：**
- `默认` — 跟随 SillyTavern 当前主题色
- `暗墨` — 金棕色调，适合深色界面
- `暖纸` — 暖橙色调，温暖典雅
- `松风` — 清绿色调，清新自然

**外部主题（URL 加载）：**

填写可访问的 `.css` 文件 URL，点击「加载」即可应用。CSS 内容会以 `<style>` 标签注入页面。

推荐覆盖以下 CSS 变量来定制配色：
```css
/* 主强调色（影响标题、按钮、激活状态） */
--SmartThemeQuoteColor: #your-color;

/* 边框颜色 */
--SmartThemeBorderColor: #your-color;
```

## ❓ 常见问题

**Q：安装后找不到「✦ 文字润色」按钮？**

A：确认已刷新页面（F5）。若仍找不到，检查扩展管理器中「文字润色工坊」是否已勾选启用。

**Q：连接报错 `No available channel for model XXX`？**

A：这是中转 API 的权限问题，不是扩展 Bug。你的套餐不包含该模型，请手动填写你的服务商支持的模型名称。

**Q：点击「连接并获取模型」显示「无法获取模型列表」？**

A：部分中转 API 不支持 `/v1/models` 接口，这是正常现象。直接在「当前模型」输入框手动填写模型名，或点击常用模型快速填入，不影响正常润色。

**Q：流式输出中途卡住了？**

A：点击「停止」按钮终止请求，然后重新润色。也可以尝试降低 max_tokens 或换用响应更快的模型。

**Q：如何使用官方 Anthropic API？**

A：在 API 类型中选择「Anthropic 原生」，地址填 `https://api.anthropic.com`，密钥填 `sk-ant-api03-...` 格式的 Key，点击连接即可。

**Q：Diff 视图中文字可以直接编辑吗？**

A：Diff 视图目前不支持直接文字编辑（防止浏览器插入意外标签），如需精细修改请在「修改意见」输入框描述后重新生成，或点击「应用」后在结果区直接编辑。

# 文字润色工坊 v2.2 · SillyTavern Extension

一个运行在 SillyTavern 内的 AI 文字润色工具，支持中转 API 和多种主流大语言模型。

## ✨ v2.2 更新亮点

- **完美适配中转 API**：新增 API 类型选择器（OpenAI 兼容 / Anthropic 原生），中转用户不再需要特殊配置
- **手动输入模型名**：中转 API 无 `/v1/models` 端点？直接手填模型名即可
- **常用模型快速选择**：Claude / GPT / Gemini / DeepSeek / Qwen 热门模型一键填入
- **生成参数控制**：新增 `max_tokens` 和 `temperature` 设置
- **智能降级**：模型列表获取失败时自动切换手动模式，区分认证失败与不支持
- **URL 自动清理**：自动去除误加的 `/v1`、`/v1/chat/completions` 后缀

## 功能

- **魔棒按钮**：输入框上方出现「✦ 文字润色」按钮，点击即可展开弹窗
- **AI 智能润色**：自然语言输入 → 结构化高质量段落输出，流式逐字显示
- **9 种风格**：文学叙事 / 诗意朦胧 / 古典雅致 / 浪漫细腻 / 戏剧张力 / 极简冷峻 / 奇幻绮丽 / 暗黑哥特 / 自定义
- **5 档强度**：从轻微优化到完全重塑
- **快速预设标签**：多选附加要求
- **深度润色 + Diff 对比**：输入修改意见重写，Diff 视图直观展示前后差异，支持逐段选择保留
- **一键导入**：从当前对话导入最新 AI 消息
- **发送到输入框**：润色结果一键填入 ST 输入框

## 安装

1. 打开 SillyTavern → 扩展图标 → 安装扩展
2. 粘贴仓库地址：
   ```
   https://github.com/luoxinyu719/st-text-polish
   ```
3. 安装后刷新页面（F5）

## 使用

### 基本流程

1. 在 ST 对话界面，输入框**上方**会出现 **「✦ 文字润色」** 按钮
2. 点击打开弹窗 → 切换到 **⚙ API** 标签页
3. 填写 API 地址 + 密钥，点击「连接」，自动拉取可用模型
4. 回到「✦ 润色」标签页，选好风格和强度，输入文字，点「开始润色」

### 中转 API 用户指南

1. **API 类型**选择 `OpenAI 兼容（中转 API 选此项）`
2. **API 地址**填写中转服务商提供的地址（如 `https://api.example.com`），无需加 `/v1` 后缀
3. **API 密钥**填写你的中转密钥
4. 点击「连接并获取模型」：
   - 如果中转支持 `/v1/models`，会自动列出可用模型
   - 如果不支持，会自动切换到手动模式，在「当前模型」输入框直接填入模型名（如 `claude-sonnet-4-20250514`）
5. 也可以使用下方的**常用模型快速填入**按钮

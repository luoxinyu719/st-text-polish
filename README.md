# 文字润色工坊 v2.3 · SillyTavern Extension

一个运行在 SillyTavern 内的 AI 文字润色工具，支持中转 API 和多种主流大语言模型。

## ✨ v2.3 更新亮点

- **导入 ST 输入框文字**：一键将 SillyTavern 输入框中已有的文字导入到润色区，无需手动复制粘贴
- **API 双配置槽**：可同时保存两套 API 配置（配置1 / 配置2），随时一键切换，方便在不同服务商之间快速切换
- **润色历史记录**：每次润色完成后自动保存（最多 3 条），在「润色」Tab 折叠区或「📋 历史」Tab 中查看、复用、复制
- **外部主题 CSS**：新增「🎨 主题」Tab，填入公开 CSS URL 即可实时加载自定义外观
- **Prompt 模板编辑**：在 API Tab 折叠面板中自定义 System Prompt 与润色主模板，支持 `{{styleDesc}}`、`{{intensityDesc}}`、`{{presets}}`、`{{extraNote}}`、`{{inputText}}` 五个占位符

## 安装

1. 打开 SillyTavern → 扩展图标 → 安装扩展
2. 粘贴仓库地址：
   ```
   https://github.com/luoxinyu719/st-text-polish
   ```
3. 安装后刷新页面（F5）

## 使用

### 基本流程

1. 在 ST 对话界面，输入框**上方**会出现 **「✦ 文字润色」** 按钮
2. 点击打开弹窗 → 切换到 **⚙ API** 标签页
3. 选择 API 类型，填写 API 地址 + 密钥，点击「连接并获取模型」
4. 回到「✦ 润色」标签页，选好风格和强度，输入或导入文字，点「开始润色」

### 中转 API 用户指南

1. **API 类型**选择 `OpenAI 兼容（中转 API 选此项）`
2. **API 地址**填写服务商提供的地址（如 `https://api.example.com`），**无需**加 `/v1` 后缀
3. 点击「连接并获取模型」：
   - 支持 `/v1/models` 的会自动列出可用模型
   - 不支持的会自动切换到手动模式，在「当前模型」输入框直接填入模型名
4. 也可使用**常用模型快速填入**按钮（Claude / GPT / Gemini / DeepSeek / Qwen）

### API 双配置槽

- API Tab 顶部有「配置 1」和「配置 2」两个按钮
- 每套配置独立保存 API 地址、密钥、类型、模型
- 点击「保存此配置」保存当前填写内容，点击对应按钮即可切换

### Prompt 模板编辑

- 在 API Tab 最底部展开「Prompt 模板编辑（高级）」
- **System Prompt**：发送给 AI 的角色设定
- **润色主 Prompt**：支持以下占位符自动替换：
  - `{{styleDesc}}` — 当前选择的风格描述
  - `{{intensityDesc}}` — 当前强度说明
  - `{{presets}}` — 已选的快速预设
  - `{{extraNote}}` — 额外要求
  - `{{inputText}}` — 待润色的文本
- 点击「重置默认」可还原内置模板
